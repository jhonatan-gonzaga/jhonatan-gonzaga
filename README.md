Sobre mim

Sou estudante de Engenharia de Software na Universidade Federal do Amazonas. Tenho interesse em projetos que conectam fundamentos de software, inteligência artificial e análise visual.

No GitHub, organizo estudos e projetos acadêmicos em linguagens como TypeScript, Python, C, JavaScript e HTML. Meu objetivo é construir uma base sólida para criar aplicações que trabalhem com imagens, dados e interfaces simples de acompanhar.
